# Fritchii-HDrum v5.6

This changelog lists only the additions and modifications made specifically in Fritchii-HDrum. Upstream Fritchii changes are intentionally not repeated here.

## RenHDrum 0.3.0: HD Rumble and controller haptics

- Integrated **RenHDrum v0.3.0** with runtime loading of `renhdrum.dll`.
- Added calibrated **Switch 2 HD Rumble** output for supported Nintendo Switch Pro Controllers and Joy-Con, including the Switch 2 Mode 2 vibration path.
- Added detailed **DualSense and DualSense Edge haptics**, using the controller's haptic voice coils. Wired USB and supported Bluetooth paths are handled by the integration.
- Added **Xbox-style controller rumble** with RenHDrum and Direct modes, motor strength, detail, hit accents, and trigger-rumble controls where the controller and input path expose trigger motors.
- Added a dedicated **HD Rumble settings** page for overall intensity, weak-rumble boost, USB packet timing, Bluetooth levels, DualSense haptics, and Xbox motor options.
- Integrated RenHDrum's **SDL3 HD Rumble transport patches** so Switch controller rumble packets can be sent using the required timing and transport behavior.

**Settings path:** Configure (Ctrl + ,) → Controls → Configure (under Vibration) → HD Rumble.

## Controller configuration improvements

- Fixed the Controls page layout so the controller mapping columns and right-hand controls are no longer clipped.
- The controller preview now scales to fit the available space instead of drawing at a fixed size.
- Compact mapping buttons, group boxes, and player tabs so the controls fit more cleanly.
- Reduced the device selector's minimum width so the Profile controls remain visible.
- Increased the configuration dialog's default size to give the Controls page more room.

## Windows release package

- Includes `renhdrum.dll` and the required runtime files for the HD Rumble integration.
- Includes the official **Ocarina of Time v131072 / shader cache v54 recipe** used by this Fritchii-HDrum package.
- The release workflow now rebuilds only `lichii.exe` and reuses the verified v5.6 runtime package for DLLs, Qt plugins, SDL3 files, and other unchanged assets.
- Ships the Windows x64 MSVC build.
