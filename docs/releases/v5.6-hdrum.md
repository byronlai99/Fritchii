# Fritchii-HDrum v5.6

This release combines the upstream Fritchii v5.6 update with Fritchii-HDrum's RenHDrum integration and Windows-specific fixes.

## Ocarina of Time

- **AMD upscaling options:** Added AMD FSR 3.1 and FSR 4 as Ocarina of Time anti-aliasing/upscaling choices. FSR 4 uses AMD's official FidelityFX runtime, downloaded on request.
- **High refresh rate mode (experimental):** Toggle the mode while the game is running with `Ctrl+U`. Set the refresh-rate cap in Graphics > Advanced. The game remains at normal speed, and water ripples continue animating above 60 FPS.
- **Movie presentation:** Added an Ocarina of Time movies option for Automatic, Bilinear, or the game's own upscaler. On supported NVIDIA RTX hardware, the game's own path restores its video-processing effects.
- **DLSS/FSR rendering corrections:** Preserve the camera jitter and texture LOD bias needed by the game's upscaling passes.
- **Built-in Dynamic FPS:** The standalone Dynamic FPS mod is automatically skipped and hidden when the built-in implementation is enabled, avoiding overlap.

## Performance and stability

- **RAM and VRAM visibility:** The performance overlay now reports RAM and VRAM usage, including remaining memory.
- **Lower memory pressure:** Improved handling of zeroed guest pages, stale render targets, and GPU pipeline cache entries to reduce unnecessary host RAM/VRAM use during longer sessions.
- **Less GPU submission overhead:** Avoids empty Vulkan command submissions and reduces repeated allocation overhead in query and fence reporting.
- **Shader and rendering stability:** Fixes include compute-shader write tracking, AMD mesh-shader fallback behavior, and safer handling of video decoder failures.
- **Video playback:** Ocarina cutscene and menu video presentation is synchronized more closely with audio; a bad frame or decoder failure should no longer take down the game.
- **Settings recovery:** Reset to Defaults now saves a backup, and Restore Settings can bring a saved settings set back.

## Audio and controller improvements

- **Switch 2 microphone capture:** Adds microphone input capture support and a silent fallback when the host microphone cannot be opened, preventing the Ocarina microphone path from crashing.
- **Controls layout repair:** Fixes the cramped/overflowing controller configuration page. The controller preview scales to fit, mapping controls and group boxes use a compact layout, player tabs fit more cleanly, and the device list no longer pushes Profile controls out of view.
- **Larger configuration window:** The settings dialog opens at a wider size to better accommodate the Controls layout.

## Fritchii-HDrum

- **RenHDrum v0.3.0 integrated:** Adds HD Rumble support for compatible controllers.
- **HD Rumble settings:** Configure (Ctrl + ,) → Controls → Configure (under Vibration) → HD Rumble.

## Build

- Windows x64 MSVC release package.
- This is a Fritchii-HDrum build; the release ZIP includes the emulator and required runtime files.
